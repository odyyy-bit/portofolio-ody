# Odyantoro Portfolio

Website personal portfolio dibangun menggunakan **React JS** dan **Vite** dengan dukungan ganti tema **Hitam (Dark Mode)** dan **Putih (Light Mode)**.

## Menjalankan Proyek

```bash
npm install
npm run dev
```

## Panduan Mengganti Data & Foto

- `src/data/profileData.js`: Nama, teks *typing*, deskripsi, foto profil (`avatarUrl`), biodata, nomor WhatsApp, email, dan tautan media sosial.
- `src/data/skillsData.js`: Ganti `cutoutPhoto` dengan foto Anda format PNG tanpa latar belakang (*transparent background*) serta daftar logo aplikasi yang berputar mengelilingi foto.
- `src/data/projectsData.js`: Daftar proyek, kategori, teknologi, gambar, serta link Live Demo & GitHub.
- `src/data/experienceData.js`: Riwayat pengalaman asli.
- `src/data/educationData.js`: Riwayat pendidikan.
- `src/data/certificatesData.js`: Galeri sertifikat.
